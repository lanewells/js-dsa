# js-dsa

## Instructions

### To add new problem:

1. `mkdir problem-name`
2. `touch problem-name/index.js problem-name/index.test.js`

### To run terminals:

(from root directory)

#### Terminal 1

`npm test`

#### Terminal 2

`node --watch scratch.js`

#### Commands in vitest terminal

p -> filter to current filename
a -> back to running all
q -> quit
